# Phase-3-Production-Design/02_GLOBAL_VISUAL_LANGUAGE.md

# Global Visual Language

Version 1.0

---

# Purpose

This document defines the visual language shared by every world.

Consistency should emerge from principles.

Not repetition.

---

# Overall Style

Editorial.

Architectural.

Cinematic.

Museum-like.

Minimal.

Human.

Never futuristic.

Never cyberpunk.

Never AI-themed.

---

# Shapes

Large simple geometry.

Soft bevels.

Rounded edges only where they improve approachability.

Avoid random abstract geometry.

Every object should possess purpose.

---

# Scale

Large hero objects.

Small interface.

Visitors should feel surrounded by ideas.

Not controls.

---

# Composition

Every scene should possess

One dominant object.

One supporting object.

One area of rest.

Avoid visual competition.

---

# Texture

Natural.

Stone.

Glass.

Metal.

Paper.

Wood.

Fabric.

No noisy textures.

No visual clutter.

---

# Contrast

Contrast should be created through

Light.

Scale.

Spacing.

Material.

Not bright colours.

---

# Interface

Minimal.

Floating.

Respectful.

Secondary.

The interface never competes with the environment.

---

# Glass

Glass communicates depth.

Not trendiness.

Use sparingly.

Navigation.

Cards.

Project expansions.

Never entire pages.

---

# Motion

Every visual movement should support understanding.

The environment itself should feel alive.

Not animated.

Subtle difference.

---

# Colour

Projects own atmosphere.

The portfolio owns restraint.

Consistency should emerge through

Typography.

Spacing.

Materials.

Motion.

Composition.

Never identical colours.

---

# Success

The visitor should recognise the portfolio

without relying on logos or branding.
