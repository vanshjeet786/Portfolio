# Phase-2-Experience/04_NAVIGATION.md

# Navigation System

Version 1.0

---

# Philosophy

Navigation is not a menu.

Navigation is orientation.

Its purpose is to quietly answer three questions.

Where am I?

Where have I been?

Where can I go?

Nothing more.

---

# Primary Behaviour

The navigation should never become the primary visual element.

It quietly accompanies the visitor.

Like a museum guide.

Not a GPS.

---

# Placement

Top-right corner.

Inspired by AllGood Studio.

Compact.

Persistent.

Always visible.

Never dominant.

---

# Components

Journey Progress

Current World

Project Index

Interaction Indicator

Optional Audio Toggle

No traditional navigation bar.

---

# Journey Progress

The visitor should always understand

how much of the journey remains.

Avoid percentages.

Avoid progress bars.

Instead,

represent progress as movement through chapters.

---

# Chapter Structure

Introduction

The navigation should subtly highlight the current chapter.

---

# Interaction Behaviour

Hover

Navigation expands.

Displays chapter names.

Scroll

Navigation updates smoothly.

Click

Transitions gracefully to another world.

Never jump instantly.

Maintain cinematic continuity.

---

# Mobile Behaviour

Collapse into a compact floating element.

Expand only when requested.

Never occupy excessive screen space.

The journey remains readable.

---

# Tablet Behaviour

Persistent.

Slightly larger touch targets.

Preserve hierarchy.

---

# Scroll Indicator

Scrolling should communicate progression.

Not page length.

As visitors move,

the indicator evolves.

Avoid linear bars.

Instead,

think of a journey marker.

---

# World Indicator

Every world receives a unique icon.

Not literal.

Career Compass

Compass mark.

Skillometer

Adaptive node.

Exiles

Signal.

Leaderboard

Ranking pillar.

Stance

Gallery frame.

Icons should feel designed.

Not illustrative.

---

# Active State

The current world should feel

anchored.

Not highlighted.

Subtle typography changes.

Gentle scaling.

Small motion.

Avoid bright colours.

---

# Transition Behaviour

Changing worlds should preserve continuity.

The navigation should move with the journey.

Not reload.

---

# Accessibility

Keyboard accessible.

Visible focus.

Readable labels.

Reduced motion support.

Large touch targets.

---

# Things To Avoid

Hamburger menus.

Large sticky headers.

Traditional navbars.

Heavy glass panels.

Large logos.

Bright hover colours.

Complex dropdowns.

---

# Inspiration

AllGood Studio

The restraint.

Not the styling.

Museum signage.

Architectural wayfinding.

Editorial layouts.

Physical exhibitions.

---

# Final Principle

Visitors should rarely think about navigation.

If they notice it,

it should be because it quietly helped them,

never because it demanded attention.
