# Phase-2-Experience/05_SCENE_PROGRESSION.md

# Scene Progression

Version 1.0

---

# Purpose

This document defines how the experience progresses from scene to scene.

A scene is not a page.

A scene is a moment.

Each scene should communicate exactly one idea before naturally evolving into the next.

---

# Philosophy

Never teleport the visitor.

Every transition should preserve spatial continuity.

The visitor should always understand

where they came from,

where they are,

where they are going.

---

# Scene 01

Arrival

Purpose

Introduce atmosphere.

Visual

Dark canvas.

Breathing cube.

Minimal interface.

Emotion

Curiosity.

Duration

8–12 seconds.

Interaction

Observe.

Recognition

Visual

Cube slowly transforms.

Typography fades into focus.

True Focus animation.

Emotion

Recognition.

Interaction

Scroll.

# Scene 03

Purpose

Purpose

Reveal motivation.

Whitespace.

Connection.

# Scene 04

Purpose

Transition into exploration.

Visual

Anticipation.

# Scene 05

Career Compass

Purpose

Introduce product thinking.

Hero Object

Compass.

Primary Motion

Orbital movement.

Camera

Slow.

Observational.

Ending

Constellations dissolve.

# Scene 06

Skillometer

Purpose

Introduce systems thinking.

Hero Object

Living intelligence.

Primary Motion

Organic growth.

Interaction

Cursor influences network.

Expand interaction reveals architecture.

Ending

Network simplifies into communication paths.

# Scene 07

Exiles

Purpose

Introduce realtime systems.

Hero Object

Signal network.

Primary Motion

Continuous flow.

Interaction

Messages travel.

Presence pulses.

Ending

Signals compress into score packets.

---

# Scene 08

Leaderboard

Purpose

Introduce backend engineering.

Hero Object

Validation pipeline.

Primary Motion

Directional movement.

Interaction

Packets validated.

Accepted packets continue.

Rejected packets dissolve.

Ending

Industrial structure softens.

# Scene 09

Stance

Purpose

Demonstrate craftsmanship.

Hero Object

Anatomical model.

Primary Motion

Museum pacing.

Interaction

Camera reveals details.

Lighting guides focus.

Ending

Environment becomes minimal.

---

# Scene 10

Reflection

Purpose

Reveal patterns.

Instead of another project,

the visitor recognises

the same engineer behind every project.

Visual

Minimal.

No hero object.

Only thoughtful composition.

---

# Scene 11

Creator

Purpose

Introduce the person.

Portrait.

Resume.

Links.

Very little copy.

No timeline.

No autobiography.

Projects have already introduced the creator.

---

# Scene 12

Conversation

Purpose

Allow visitors to leave naturally.

Final sentence.

Socials.

Contact.

No aggressive CTA.

No animation spectacle.

The portfolio quietly ends.

---

# Scene Rules

Every scene contains

One purpose.

One hero.

One emotion.

One interaction.

One memorable transition.

Nothing more.

---

# Scene Rhythm

Stillness

↓

Motion

↓

Stillness

↓

Discovery

↓

Reflection

↓

Continuation

This rhythm should repeat throughout the experience.

---

# Success

A visitor should remember

moments,

not sections.
