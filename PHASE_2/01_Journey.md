# Journey

Version 1.0

---

# Purpose

This document defines the emotional and experiential journey of the visitor.

Not the UI.

Not the pages.

Not the implementation.

The journey.

Every later design decision should preserve this sequence.

Changing the order changes the story.

---

# Design Goal

Visitors should never feel that they are navigating.

They should feel that they are discovering.

The portfolio should resemble an exhibition.

Not software documentation.

---

# Stage 01

Arrival

Duration

5–10 seconds

Emotion

Curiosity

Purpose

Slow the visitor down.

Do not immediately explain anything.

The visitor should instinctively stop scrolling.

The experience must communicate quality before information.

The visitor should think

"This feels different."

Nothing more.

---

# Stage 02

Identity

Duration

10–15 seconds

Emotion

Recognition

Purpose

Reveal only

Name

Role

One sentence.

Nothing else.

The website should avoid introducing projects immediately.

People remember people.

Not products.

---

# Stage 03

Purpose

Duration

15–25 seconds

Emotion

Connection

Purpose

Reveal

"I love solving problems."

No supporting paragraphs.

The next twenty minutes of exploration should become proof of that sentence.

---

# Stage 04

Invitation

The visitor chooses to continue.

Not because they have to.

Because curiosity exists.

This transition is extremely important.

The portfolio should never feel linear.

It should feel willingly explored.

---

# Stage 05

Worlds

Visitors begin travelling through projects.

Every transition should feel meaningful.

Every world should reset emotion.

Every world should have its own atmosphere.

Never repeat visual language.

Never repeat interaction.

Only philosophy should remain consistent.

---

# Stage 06

Recognition

Visitors begin recognising patterns.

Product thinking.

System thinking.

Calm interaction.

Thoughtful engineering.

They stop evaluating projects individually.

They begin evaluating the creator.

This is the turning point.

---

# Stage 07

Trust

Visitors understand

how the creator thinks.

Technology becomes secondary.

Judgement becomes primary.

The visitor should now believe

"I would trust this person."

---

# Stage 08

Conversation

The ending should never feel like an ending.

It should feel like an invitation.

No dramatic CTA.

No "Hire Me".

No animated fireworks.

Simply

Portrait.

Resume.

Links.

One sentence.

The conversation should continue outside the portfolio.

---

# Journey Rules

Never overwhelm.

Never rush.

Never repeat.

Never interrupt curiosity.

Never explain before creating interest.

Always reward exploration.

Always create continuity.

Always preserve emotional pacing.

---

# Success Metric

The visitor should remember

the journey,

not the navigation.
