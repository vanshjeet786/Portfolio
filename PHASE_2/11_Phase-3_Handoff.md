# Design Standard

Phase 3 should behave like a production designer creating environments for a film.

Not a UI designer decorating screens.

The worlds should be believable.

They should possess

history,

materials,

light,

weight,

silence,

and atmosphere.

---

# Technical Standard

Every visual decision should answer

"What does this communicate?"

Never

"What looks cool?"

The portfolio has now moved beyond interface design.

It has entered environmental storytelling.

---

# Final Statement

If Phase 1 defined the philosophy,

and Phase 2 designed the journey,

then Phase 3 gives that journey a physical form.

Nothing should be invented.

Everything should emerge naturally from the documents that already exist.
