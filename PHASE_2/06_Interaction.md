# Phase-2-Experience/06_INTERACTION_MAP.md

# Interaction Map

Version 1.0

---

# Purpose

This document defines every category of interaction throughout the portfolio.

Interactions are not animations.

They are conversations between the visitor and the interface.

Every interaction should produce understanding.

---

# Interaction Hierarchy

Observe

↓

Hover

↓

Scroll

↓

Explore

↓

Expand

↓

Understand

Every interaction increases understanding.

Never complexity.

---

# Observation

The default state.

Nothing asks for attention.

The interface waits.

Visitors decide when to interact.

This creates confidence.

---

# Hover

Purpose

Communicate possibility.

Hover should never reveal everything.

Instead,

it should suggest

"There is more."

Examples

Cursor reacts.

Object responds.

Light changes.

Typography shifts.

Glass catches light.

No dramatic movement.

---

# Cursor

Default

Small.

Quiet.

Almost invisible.

Hover

Soft magnetic attraction.

Elastic easing.

Gentle scale increase.

Interactive Object

Cursor transforms into intent.

It subtly communicates

"You can explore."

No exaggerated blobs.

No oversized circles.

No distracting gimmicks.

---

# Scroll

Purpose

Move through the narrative.

Never simply move content.

Scroll should

Change lighting.

Move camera.

Reveal geometry.

Advance timelines.

Build understanding.

---

# Expand

Every project contains one primary expansion point.

Expansion should reveal

Problem.

Architecture.

Engineering.

Screenshots.

Stack.

Never open a modal.

Never navigate away.

The experience remains continuous.

---

# Project Objects

Every world has one hero object.

Career Compass

Compass.

Skillometer

Living intelligence.

Exiles

Signal network.

Leaderboard

Validation pipeline.

Stance

Anatomical model.

Interaction should begin with these objects.

Not buttons.

---

# Image Interaction

Screenshots should never simply enlarge.

They should become contextual.

Visitors should understand

why they are seeing the screenshot.

Where it belongs.

What changed.

---

# Navigation

Hover

Expand.

Scroll

Update.

Click

Transition.

Navigation should never interrupt the story.

---

# Motion Feedback

Every interaction should acknowledge the visitor.

Light.

Depth.

Scale.

Shadow.

Motion.

Feedback should be immediate.

Never exaggerated.

---

# Mobile Interaction

No hover assumptions.

Replace hover with

Touch.

Hold.

Progressive reveal.

Keep gestures simple.

Avoid hidden interactions.

---

# Tablet Interaction

Larger touch areas.

Preserve desktop hierarchy.

Respect thumb reach.

---

# Accessibility

Every interaction must have

Keyboard equivalent.

Visible focus.

Reduced motion version.

Readable state.

No interaction should require precision.

---

# Forbidden Interactions

Auto-playing experiences.

Forced scrolling.

Unexpected camera jumps.

Infinite cursor effects.

Parallax for decoration.

Motion without meaning.

Hover-only critical information.

---

# Golden Rule

Every interaction should answer one question.

"What did I just learn?"

If the answer is

"Nothing",

remove the interaction.
