# Executive Summary

Exiles Chat demonstrates communication systems.

Unlike the other projects, its value lies in creating an experience that feels immediate, reliable and connected.

Messaging applications are deceptively simple.

Behind every message lies authentication, presence, realtime updates, database architecture and user trust.

The portfolio should present Exiles as an exercise in designing communication rather than merely building chat.
