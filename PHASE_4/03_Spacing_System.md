# Phase-4-Interaction-Language/03_SPACING_SYSTEM.md

# Spacing System

Version 1.0

---

# Philosophy

Whitespace is an interface component.

Not leftover space.

Spacing creates confidence.

Crowded layouts communicate uncertainty.

---

# Scale

Use an 8-point spacing system.

4

8

16

24

32

48

64

96

128

192

256

Never use arbitrary values.

---

# Vertical Rhythm

Every section begins with breathing room.

Every section ends with breathing room.

Transitions require additional space.

---

# Content Width

Reading Width

~700px

Interactive Width

~1200px

Environment

Full viewport

---

# Hero Sections

Never place text at screen edges.

Maintain generous margins.

---

# Cards

Padding should feel architectural.

Not app-like.

Avoid cramped layouts.

---

# Project Expansions

Large internal spacing.

Separate

Problem

Architecture

Outcome

Visually.

---

# Mobile

Reduce horizontal margins.

Preserve vertical rhythm.

Never compress spacing aggressively.

---

# Relationship Rules

Space communicates grouping.

Closer

Related.

Further

Independent.

Never rely solely on colour.

---

# Empty Space

Silence is intentional.

Visitors need places to rest.

Every world should contain visual pauses.

---

# Success

The portfolio should feel expensive.

Whitespace contributes more to that feeling than colour.
