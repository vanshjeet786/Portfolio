# Phase-4-Interaction-Language/08_ANIMATION_SYSTEM.md

# Animation System

Version 1.0

---

# Philosophy

Animation is explanation.

Not decoration.

Every animation must answer one question.

What changed?

Why?

---

# Animation Hierarchy

Micro

↓

Component

↓

Section

↓

World

↓

Journey

Each level communicates different information.

---

# Motion Principles

Weight.

Momentum.

Anticipation.

Follow-through.

Continuity.

Pause.

These principles should guide every animation.

---

# Timing

Micro

150–300ms

Component

300–600ms

Section

800–1500ms

World

2–4 seconds

Journey

Variable.

Never rush.

---

# Easing

Prefer spring-based motion.

Avoid default easing.

Movement should resemble physical objects.

Not CSS transitions.

---

# Anime.js

Reserved for

Hero objects.

Morphing.

Cube transformation.

Editorial typography.

Symbolic transformations.

Never routine UI.

---

# GSAP

Reserved for

Scroll choreography.

Camera movement.

World transitions.

Timeline orchestration.

Environmental storytelling.

---

# React Spring

Optional.

Small interactive physics.

Cards.

Hover.

Cursor.

Panels.

---

# Three.js Animation

Environmental.

Subtle.

Purposeful.

Objects should appear alive.

Never perform endlessly.

---

# Animation Budget

Every screen receives

One major animation.

Two supporting animations.

Unlimited subtle environmental behaviour.

Restraint creates memorability.

---

# Reduced Motion

Every animation has a graceful alternative.

No information may disappear when motion is disabled.

---

# Performance

Target

60 FPS.

Prefer transform.

Prefer opacity.

Avoid layout recalculation.

Profile continuously.

---

# Animation Review Checklist

Does it teach?

Does it guide?

Does it improve understanding?

Can it be removed?

If yes,

remove it.

---

# Success

Visitors should remember

what the animation explained,

not that an animation occurred.
