# Typography System

Version 1.0

---

# Philosophy

Typography is the primary interface.

Everything else supports it.

The visitor should notice the ideas.

Not the font.

---

# Emotional Goal

Editorial.

Architectural.

Calm.

Confident.

Readable.

Timeless.

---

---

---

Caption

Metadata.

Stacks.

Image labels.

---

Mono

# Line Length

55–75 characters.

Never wider.

Large screens should increase whitespace.

Not paragraph width.

---

# Rhythm

Typography should breathe.

Paragraph spacing communicates hierarchy.

Not blank divs.

---

# Alignment

Mostly left aligned.

Occasionally centred for emotional moments.

Never justify text.

---

# Colour

Typography should rarely be pure white.

Prefer warm neutrals.

Primary text.

Secondary text.

Muted text.

Disabled.

One consistent hierarchy.

---

# Motion

Typography moves as groups.

Never individual letters,

except

True Focus.

Hero identity.

Rare editorial moments.

---

# Rules

No outlined fonts.

No glowing fonts.

No gradients.

No distorted typography.

No decorative effects.

Typography earns attention through composition.

Not styling.

---

# Success

Visitors remember the message.

Not the font.
