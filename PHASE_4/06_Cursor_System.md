# Phase-4-Interaction-Language/06_CURSOR_SYSTEM.md

# Cursor System

Version 1.0

---

# Philosophy

The cursor is curiosity.

It should quietly encourage exploration.

Not perform tricks.

---

# Behaviour

Idle

↓

Aware

↓

Interactive

↓

Expanded

↓

Return

Every transition should feel elastic.

Never abrupt.

---

# Idle

Minimal.

Almost invisible.

Soft presence.

---

# Hover

Small scale increase.

Magnetic attraction.

Very subtle.

---

# Interactive

Cursor changes identity.

Instead of saying

Click

it communicates

Explore.

---

# Expand

Project objects.

Hero objects.

Images.

Architecture.

The cursor becomes slightly larger.

Movement slows.

Focus increases.

---

# Cursor Trail

Optional.

Very subtle.

High frame rate.

Fade quickly.

Never dominate.

---

# Physics

Spring.

Mass.

Momentum.

Damping.

The cursor should feel physical.

Not mathematical.

---

# Forbidden

Huge blobs.

Long trails.

Rainbow effects.

Constant morphing.

Cursor lag.

Over-designed cursors.

---

# Accessibility

Native cursor remains available.

Reduced motion disables magnetic behaviour.

No interaction should depend on custom cursor.

---

# Success

Visitors stop noticing the cursor.

They simply feel that interaction is natural.
