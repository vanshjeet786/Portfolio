# Phase-4-Interaction-Language/05_COMPONENT_LIBRARY.md

# Component Library

Version 1.0

---

# Philosophy

Components should disappear.

Experiences should remain.

The visitor should never notice reusable UI.

They should notice continuity.

Every component should feel handcrafted.

Nothing should resemble a default component library.

---

# Component Hierarchy

World

↓

↓

Component

↓

Primitive

Never design from the bottom up.

Always design from the story downward.

# Screenshot Viewer

Never open a lightbox.

Instead,

the environment expands around the screenshot.

Context remains visible.

# Architecture Viewer

Purpose

Teach.

Never overwhelm.

Architecture diagrams should animate progressively.

Systems should appear in logical order.
