# Experience Engine

## Purpose
Orchestrates the 3D WebGL / React Three Fiber experience layer, including world lifecycle management (loading, warming, unloading) and progression logic.

## Ownership
- **Owner**: Lead Product Engineer / Technical Architect

## Dependencies
Three.js, `@react-three/fiber`, `@react-three/drei`, `@/stores`, `@/systems`

## Public API
`ExperienceEngine.tsx` (R3F Canvas mounting), `useExperienceEngine()` (Lifecycle hooks)
