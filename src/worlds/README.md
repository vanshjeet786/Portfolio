# Worlds Module

## Purpose
Houses the code for individual project worlds (constellations, spaces, 3D scenes). Each project operates as its own self-contained world.

## Ownership
- **Owner**: Lead Product Engineer

## Dependencies
Three.js, `@react-three/fiber`, `@/components`, `@/systems`

## Public API
Individual world loaders (e.g. `CareerCompassWorld.tsx`)
